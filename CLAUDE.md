# Mateus Ranzani — Portfolio

## Objetivo

Este projeto consiste no desenvolvimento do meu portfólio pessoal.

O objetivo não é apenas apresentar meus projetos, mas transmitir excelência técnica, criatividade e atenção aos detalhes.

O site deve causar impacto logo no primeiro acesso e demonstrar um alto nível de qualidade tanto em design quanto em desenvolvimento.

Toda decisão técnica deve priorizar uma experiência memorável para o usuário.

# Stack

O projeto deve utilizar obrigatoriamente:

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- GSAP
- Lucide React

Sempre utilizar as melhores práticas do ecossistema React e Next.js.

---

# Biblioteca de animações

Todo o sistema de animações deve ser desenvolvido utilizando GSAP.

Sempre que possível utilizar:

- ScrollTrigger
- SplitText (quando disponível)
- Timeline
- MatchMedia
- Context API

Evitar animações feitas apenas com CSS quando elas puderem ser melhor executadas com GSAP.

---

# Filosofia do projeto

Este NÃO deve ser um portfólio comum.

Quero um site extremamente interativo.

A navegação deve parecer uma experiência, e não apenas uma sequência de páginas.

O usuário deve sentir vontade de continuar rolando para descobrir o próximo conteúdo.

As animações devem contar uma história durante toda a leitura.

Cada seção deve possuir personalidade própria.

# Experiência de Scroll

O scroll deve ser um dos protagonistas do projeto.

Sempre pensar em possibilidades como:

- elementos surgindo conforme entram na viewport
- textos revelados palavra por palavra
- letras animadas
- imagens com parallax
- sobreposição de elementos
- pin de seções
- timelines durante o scroll
- cards aparecendo em sequência
- mudança de background conforme a leitura
- transições suaves entre seções
- indicadores visuais de progresso

O objetivo é que o usuário seja conduzido naturalmente pela página.

# Código

Sempre escrever código:

- limpo
- reutilizável
- escalável
- fortemente tipado
- sem uso de any
- dividido em componentes pequenos

Evitar duplicação.

Sempre pensar em arquitetura antes da implementação.

---

# Performance

Toda animação deve ser otimizada.

Evitar:

- re-renderizações desnecessárias
- animações pesadas
- layout thrashing
- cálculos repetitivos

Sempre realizar cleanup dos efeitos do GSAP.

---

# Responsividade

O projeto deve funcionar perfeitamente em:

- Desktop
- Notebook
- Tablet
- Mobile

As animações também devem ser adaptadas para telas menores.

Nunca apenas desabilite animações sem motivo.

Utilize MatchMedia do GSAP quando necessário.

Sempre siga este fluxo:
